🧠 AIA2ndBrain

Local, iCloud-Synced AI-Augmented Second Brain System

AIA2ndBrain is a personal knowledge automation system running locally on macOS.
It continuously watches your SecondBrain iCloud Drive folder and:

✅ Detects new notes (TXT/MD/PDFs)
✅ Classifies and summarizes their content using Gemini
✅ Generates Markdown knowledge pages with metadata
✅ File-organizes them into the PARA framework
✅ Maintains an archive that grows smarter over time

Designed to feel like a personal Chief of Staff — capturing your thoughts and organizing them automatically, with zero manual drag-and-drop.

⸻

📂 Data Structure (PARA)

Your vault lives in iCloud Drive:

~/Library/Mobile Documents/com~apple~CloudDocs/SecondBrain

Inside, the system maintains:

SecondBrain/
  Inbox/
    notes/      <- Drop new .txt or .md files here
    audio/
    images/
  Projects/
  Areas/
  Resources/
  Archives/
  Reviews/

All structured notes generated by the system land under:
	•	Projects/ (active objectives)
	•	Areas/ (ongoing responsibilities)
	•	Resources/ (knowledge to reference)
	•	Archives/ (completed/dormant items)

⸻

⚙️ How It Works

Trigger	AI Action
New .txt/.md note in Inbox	Gemini classification → PARA routing → Markdown note created (title + summary)
New folder structure created or missing	Auto-heals structure at startup

Each new note becomes:

your-category/your-title-slug/index.md

With auto-generated YAML frontmatter + summary:

---
captured_at: 2025-10-27T23:14:00.123Z
area: Projects
domain: Music
type: idea
title: "Spoken Word Structure"
tags:
  - creativity
  - music
source_path: /Users/.../original.txt
---
2-3 sentence AI summary...

✅ Requirements

macOS Only (for iCloud Drive automation)
	•	Node.js ≥ 20
	•	iCloud Drive enabled
	•	Poppler installed (for PDF support in upcoming version)

brew install poppler



⸻

🚀 Setup

Clone and install dependencies:

npm install

Add your Gemini API key:

Create a .env file in repo root:

GEMINI_API_KEY=your_key_here

Start watching your vault:

npm start

Drop any .txt file into:

iCloud Drive → SecondBrain → Inbox → notes

✅ It will auto-classify + store as Markdown
✅ You’ll see logs in terminal showing routing + naming
